Detailed Description

template<class T, std::size_t... Dimensions>
template<class ElemT>
class ysc::matrix< T, Dimensions >::enumerate_range< ElemT >

Range type returned by enumerate() that pairs coordinates with element references.

Template Parameters
ElemTElement type (possibly const — controls mutability of the reference)

Iterating over this range yields std::pair<std::array<std::size_t, order>, ElemT&> in row-major order. When ElemT is non-const, mutations to the second member of the pair are reflected in the original matrix.
