Produces nested bracket notation: [e0, e1, ...] for 1D, [[e00, e01], [e10, e11]] for 2D, and so on recursively.

This overload only participates in overload resolution when T is streamable, so it never causes a hard error for non-streamable element types.

ysc::matrix<int, 2, 2> m{1, 2, 3, 4};
std::cout << m; // [[1, 2], [3, 4]]

Produces nested bracket notation: [e0, e1, ...] for 1D, [[e00, e01], [e10, e11]] for 2D, and so on recursively. The output format is identical to that of operator<<(ostream, matrix).

ysc::matrix<int, 2, 3> m{1, 2, 3, 4, 5, 6};
std::cout << m.row(0); // [1, 2, 3]
