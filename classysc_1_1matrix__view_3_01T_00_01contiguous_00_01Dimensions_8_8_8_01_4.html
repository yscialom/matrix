Detailed Description

template<class T, std::size_t... Dimensions>
class ysc::matrix_view< T, contiguous, Dimensions... >

Non-owning read/write view over a contiguous sequence of T elements.

Template Parameters
TElement type
DimensionsDimensions of the view (same as the underlying matrix)

A matrix_view<T,contiguous,Dims...> holds a single raw pointer and the dimension metadata as template parameters. It does not own the memory: the lifetime of the underlying matrix (or raw array) must exceed that of the view.

Warning
Lifetime hazard: a matrix_view does not extend the lifetime of the underlying storage. Destroying the matrix (or raw array) while any view still refers to it is undefined behavior (heap-use-after-free). AddressSanitizer detects this class of error at runtime; see test/src/matrix_view_lifetime.cpp for a concrete example.

Because dimensions are part of the type, sizeof(matrix_view<T,contiguous,D...>) equals sizeof(T*) on every platform.

ysc::matrix<int, 2, 3> m{1, 2, 3, 4, 5, 6};
ysc::matrix_view<int, ysc::contiguous, 2, 3> v = m;
v(0, 0) = 99; // mutation is reflected in m
assert(m(0, 0) == 99);
