Detailed Description

template<class T, std::size_t... Dimensions>
class ysc::matrix_view< T, strided, Dimensions... >

Non-owning read/write view over a non-contiguous (strided) sequence of elements.

Template Parameters
TElement type
DimensionsDimensions of the view (kept dimensions only)

A matrix_view<T,strided,Dims...> holds a raw pointer and a strides array. Elements are accessed as:

element(c0, c1, ...) == *(_ptr + c0*strides[0] + c1*strides[1] + ...)
Note
Iterators and data() are not available (non-contiguous layout). Use operator() or at() for element access.
Warning
Destroying the underlying matrix while a view still refers to it is undefined behavior.
ysc::matrix<int, 3, 4> m{};
// Column 2: elements m(0,2), m(1,2), m(2,2) — stride 4
auto col2 = m.col(2); // matrix_view<int, strided, 3>
col2(1) = 99; // writes m(1, 2)
assert(m(1, 2) == 99);
