◆ generate() [2/2]

template<class T , std::size_t... Dims, detail::coord_generator< T, Dims... > MultiIndexF>
constexpr matrix< T, Dims... > ysc::generate ( MultiIndexF  f)
constexpr

Returns a matrix filled by calling f(i₀, i₁, …) for each N-D coordinate.

This overload accepts a callable that takes sizeof...(Dims) arguments of type std::size_t — one per dimension, in row-major order. It is selected when f is not callable with a single std::size_t (which would select the linear-index overload instead, preserving backward compatibility).

Template Parameters
TElement type
DimsDimensions of the result matrix
FCallable type: f(i₀, …, iₙ) must be convertible to T
Parameters
fGenerator callable receiving the N-D coordinates
Returns
New matrix<T, Dims...> where element at (i₀,…,iₙ) equals f(i₀,…,iₙ)
// 3×3 identity matrix
auto I = ysc::generate<int, 3, 3>([](std::size_t i, std::size_t j) {
return i == j ? 1 : 0;
});
// Tensor: m(i,j,k) = i*100 + j*10 + k
auto m = ysc::generate<int, 2, 3, 4>([](auto i, auto j, auto k) {
return int(i * 100 + j * 10 + k);
});
