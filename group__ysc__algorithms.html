Applies a function to every element in place.

Template Parameters
FCallable type — must satisfy std::invocable<F, T&>
Parameters
fFunction to apply to each element

Visits every element in row-major order and calls f with a reference to the element. f may modify the element; the matrix is mutated in place.

ysc::matrix<int, 3> m{1, 2, 3};
m.apply([](int& v) { v *= 2; });
// m == ysc::matrix<int, 3>{2, 4, 6}

Returns a new matrix obtained by applying a function to every element.

Template Parameters
FCallable type — must satisfy std::invocable<F, const T&>
Parameters
fFunction to apply to each element
Returns
A new matrix whose element type is std::invoke_result_t<F, const T&> and whose dimensions are identical to *this.

Does not modify the original matrix.

ysc::matrix<int, 3> m{1, 2, 3};
auto s = m.map([](int v) { return std::to_string(v); });
// s is ysc::matrix<std::string, 3>{"1", "2", "3"}
