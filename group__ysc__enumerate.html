Returns a const range of (coordinates, value) pairs in row-major order.

Returns
An enumerate_range<const T> whose iterator yields std::pair<std::array<std::size_t, order>, const T&>

Read-only variant of enumerate(). No mutation is possible through the returned range.

const ysc::matrix<int, 2, 3> m{1, 2, 3, 4, 5, 6};
for (const auto& [coords, val] : m.enumerate()) {
// coords == {0,0},{0,1},{0,2},{1,0},{1,1},{1,2} in order
// val is a const int&
}

inlineconstexprnoexcept

Returns a range of (coordinates, value) pairs in row-major order.

Returns
An enumerate_range<T> whose iterator yields std::pair<std::array<std::size_t, order>, T&>

Each iteration step exposes both the N-D coordinates (as a std::array<std::size_t, order>) and a mutable reference to the element. Mutations are reflected in the original matrix.

ysc::matrix<int, 2, 3> m{1, 2, 3, 4, 5, 6};
for (auto [coords, val] : m.enumerate()) {
// coords == {0,0},{0,1},{0,2},{1,0},{1,1},{1,2} in order
val *= 10; // mutates m
}
